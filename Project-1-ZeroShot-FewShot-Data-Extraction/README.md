# Project 1 - Zero-Shot & Few-Shot Data Extraction

## Overview

This project demonstrates how Large Language Models (LLMs) can transform unstructured text into structured JSON using prompt engineering techniques.

The prompt combines Zero-Shot instructions with Few-Shot examples to guide the model toward deterministic and consistent outputs.

---

## Objectives

- Extract structured information from messy text.
- Produce valid JSON output only.
- Improve consistency using Few-Shot prompting.
- Handle missing information gracefully.

---

## Features

- Zero-Shot prompting
- Few-Shot learning examples
- Structured JSON extraction
- Deterministic output format
- Missing value handling

---

## Files Included

- Prompt.txt
- TestCases.txt
- Results.txt

---

## Outcome

This project demonstrates reliable information extraction using prompt engineering without model fine-tuning.
